# MemeDrop

Windows 桌面表情素材庫。從聊天輸入框按 **Ctrl+Alt+M** 叫出視窗，搜尋、選取，再將圖片、GIF、影片或顏文字貼回原視窗。

## 開始使用

1. 雙擊 `start.bat`。目前專案環境已安裝相依套件；若在新電腦執行原始碼，先安裝 Python 3.10+ 並執行 `setup.bat`。
2. 將素材放進本目錄的 `memes/`，可含子資料夾；也可點「匯入素材」或拖入視窗。匯入會複製檔案，重名會加流水號，保留來源。
   經由「匯入素材」或拖入的圖片，會先在本機辨識畫面文字並用來命名；沒有文字或辨識失敗時保留原檔名，副檔名與原始內容保持不變。動圖會抽樣最多五個畫面，影片沿用原檔名。辨識到的完整文字也可搜尋；特殊標點轉為可用的全形符號，同名自動加序號。匯入前可取消文字辨識，取消時不會複製任何素材；直接放入 `memes/` 掃描的既有檔案不會自動改名。
3. 在微信、Slack、Discord、LINE、Facebook、QQ 等聊天輸入框按 `Ctrl+Alt+M`。
4. 搜尋檔名或標籤，雙擊素材或點「貼到原視窗」。貼上後，請在聊天軟體確認發送。

**獨立執行檔：** `dist/MemeDrop/MemeDrop.exe`。搬到其他電腦時，複製整個 `dist/MemeDrop` 資料夾（包含 `_internal`），不需安裝 Python。留在本專案內時使用專案根目錄的 `memes`；搬走後使用執行檔旁的 `memes`。也可用 `--library "D:\MyMemes"` 指定包含 `memes` 的根目錄。

## 功能

- 內建 **1,041 個顏文字、58 種分類**，每個都有標籤，不需下載素材即可使用；也可新增、編輯自己的顏文字。
- 全域快捷鍵，可在設定改成其他 `Ctrl+Alt+字母`，衝突會提示。
- 圖片縮圖、GIF 動畫預覽、影片播放／暫停／時間軸，預設靜音。
- 搜尋檔名、子資料夾路徑、顏文字名稱／內容與標籤，英文不分大小寫，中文不分繁簡體；空白分隔多個關鍵字代表全部符合，回收站也適用。
- 「我的表情包」、「我的顏文字」、「內建顏文字」與每個自訂表情包系列分區瀏覽，各區塊有獨立標籤。
- 各區塊內可篩選標籤、格式、收藏、最近使用、尚未標籤，並按名稱／新增時間／使用次數排序。
- 從影片辨識字幕台詞、擷取完整畫面並建立系列；可預覽及修正台詞，以台詞命名圖片，重複名稱自動加序號。
- 集合可重新命名、依名稱搜尋，或將整個集合的素材併入另一集合。
- 多選後批次追加或取代標籤；右鍵標籤可重新命名、合併、移除，只影響目前區塊。
- 選取表情包後按 F2 或「修改檔名」，直接修改素材檔名並保留標籤、系列、收藏與使用紀錄。
- 選取素材後按 Delete 或「移入回收站」，可在回收站還原、永久刪除或清空，支援多選。
- 自動貼回原視窗、只複製、將原始檔案直接拖出到聊天軟體。
- 視窗開啟時每 5 秒檢查素材變更；再次叫出或按 F5 也會重新掃描。
- 關閉／Esc 收到系統匣，右鍵系統匣圖示選「結束」；不會自動加入開機啟動。

## 我的區塊與表情包系列

- **我的表情包**：自己匯入、尚未歸入系列的圖片、GIF 與影片。
- **我的顏文字**：自己新增的顏文字，和內建庫分開。
- **我的表情包系列**：點「從影片擷取台詞建立系列」讀取影片並建立台詞截圖集合；標題旁「＋」可建立空白集合。每個系列是獨立區塊，也能匯入、拖入素材，或右鍵單個／多個素材透過「移至區塊」整理。素材只屬於一個區塊，調整集合時保留標籤、收藏與使用紀錄。
- **內建顏文字**：獨立保存內建分類及標籤。

標籤清單、數量及重新命名／合併／移除操作均以目前區塊為範圍；即使不同區塊有同名標籤，也各自獨立。收藏、最近使用、尚未標籤及搜尋也只篩選目前區塊；切換區塊會清除先前的搜尋與篩選。

所有區塊的搜尋都採用相同規則：例如 `Happy`、`HAPPY`、`happy` 可互相匹配，`開心` 與 `开心`、`貓咪` 與 `猫咪` 也可互相匹配；中英文可混合搜尋。繁簡轉換僅用於比對，原始檔名、顏文字與標籤的寫法會保留。

首次升級時，既有 `memes/` 子資料夾會依第一層資料夾名稱歸入系列，例如 `memes/貓咪/開心.gif` 歸入「貓咪」。之後新掃描到的子資料夾素材也會如此歸類；已手動調整的所屬區塊會保留，不會被重新掃描覆蓋。既有素材的標籤、收藏與使用紀錄會保留。

## 標籤層級與無標籤篩選

中央「無標籤」按鈕可清除文字及標籤條件，篩選目前區塊尚未套用任何標籤的素材；也可從篩選下拉選單選「尚未標籤」。

標籤欄右側的下拉箭頭可開啟目前區塊的標籤清單，直接點選整列即可勾選／取消多個標籤；也可按方向鍵 ↓ 開啟。上方可搜尋已有標籤，或輸入新名稱後按 Enter／「新增輸入的標籤」。搜尋支援英文不分大小寫、中文不分繁簡體。完成選擇後，仍需按原本的儲存按鈕才會套用；也可直接在標籤欄輸入，以逗號分隔多個標籤。表情包、顏文字編輯及父子標籤欄位均支援此操作。

左側「管理標籤層級」可下拉多選或輸入一個標籤的多個父標籤、多個子標籤，並在下方關係表選取標籤編輯。清空父／子欄位並儲存可解除關係。各區塊的層級獨立，禁止自我關聯及循環；選取父標籤會包含子孫標籤的表情，數量按表情去重。

一張表情可套用多個標籤。卡片、提示及編輯欄只顯示其中沒有更下層已套用標籤的項目：例如「動物 → 貓 → 橘貓」同時套用時，只顯示「橘貓」；另一分支的「狗」會同時顯示。僅套用「動物」時仍顯示「動物」，不會自動套用未選擇的子標籤。儲存葉端標籤後，仍可透過祖先標籤搜尋或篩選。併入集合時會合併標籤層級，若兩個集合的關係合併後產生循環，操作會被拒絕。

## 從影片建立台詞集合

1. 點左側「從影片擷取台詞建立系列」，選擇影片、填寫系列名稱；也可右鍵素材庫裡的影片，選「從這部影片建立台詞系列」。
2. 預設優先讀取影片內嵌的文字字幕（多軌時優先選中文），找不到時辨識畫面上的字幕。也可選擇 UTF-8／UTF-16 的 SRT 或 VTT 外掛字幕，或切換成只辨識畫面字幕。
3. 畫面辨識預設每 0.5 秒檢查下方 40%；依字幕位置可改為下方 60% 或全畫面，較快的台詞可縮短間隔。連續相同的畫面字幕保留一張，稍後再次出現的台詞仍會保留。內嵌文字／外掛字幕則依字幕時間軸擷取中間畫面，並可將文字字幕繪入截圖。
4. 點「開始擷取」，過程可停止。完成後雙擊左欄縮圖可看大圖，直接修改台詞欄可修正辨識結果；取消勾選不需要的截圖，再點「加入系列」。也能選擇加入既有集合。

截圖保留整個影片畫面。檔名使用台詞，例如 `今天也要加油.png`、`今天也要加油 (2).png`；Windows 不允許的標點改為對應全形符號，過長檔名縮短至 100 字，完整台詞仍會保存並可搜尋。檔案存入 `memes/series-集合編號/`，原影片不會被改動；集合改名不會改動已產生的台詞檔名。

所有影片與字幕處理均在本機執行，OCR 模型隨相依套件安裝，不需要上傳影片或在擷取時下載模型。畫面文字辨識可能受字型、背景及清晰度影響，匯入前可在預覽修正；PGS／DVD 等內嵌圖片字幕請先烘焙到畫面或轉成 SRT／VTT。

左側「搜尋集合名稱」支援繁簡體與英文大小寫通用；進入集合後，中央搜尋可找截圖檔名、完整台詞與標籤。右鍵集合可「重新命名集合」，或「全部併入另一集合」：將其中全部素材移到目標集合，包含目前被搜尋／篩選隱藏的素材與回收站項目的所屬集合，同名檔案自動加序號。標籤、收藏、使用紀錄會保留；來源集合保留為空集合，檔案不重複複製。

## 修改檔名與回收站

選取單個圖片、GIF 或影片，點「修改檔名」、右鍵選同名功能，或在素材格按 F2。輸入含副檔名的新檔名；副檔名須保持原本格式，不能使用路徑、Windows 保留名稱或無效字元。同名檔案不會被覆蓋。透過 App 改名會同步更新資料庫，保留該素材的標籤、系列、收藏、加入時間及使用紀錄。

點「移入回收站」、右鍵選同名功能或在素材格按 Delete，可將單個或多個表情包／顏文字移入回收站。表情包檔案會移至 `.memedrop/trash/`；顏文字保存在原資料庫中。回收站與一般區塊、標籤、收藏及最近使用分開；素材可預覽，還原後即可複製或貼上。

- 在回收站選取素材後點「還原選取」，或雙擊單個素材：回到原本區塊與系列，保留全部標籤及使用紀錄。
- 原檔名已被占用時，還原的檔案會加上 ` (2)` 等編號，保留兩份素材。若已有相同內容的顏文字，會提示先處理重複項目再還原。
- 「永久刪除」只刪除所選項目；「清空回收站」刪除回收站所有項目，包括被目前搜尋條件隱藏的項目。兩者都會先要求確認，預設取消。
- 回收站是 MemeDrop 自己管理的區塊，與 Windows 資源回收筒分開。永久刪除及清空後無法透過 App 還原；永久刪除的內建顏文字也不會在重啟時重新出現。

## 顏文字

點左側「內建顏文字」即可瀏覽內建庫，共 1,041 個不重複顏文字、58 種分類，較原本新增 801 個。涵蓋開心、大笑、難過、生氣、得意、無辜、尷尬、期待、緊張、害怕、感動、委屈、崩潰、發呆、偷看、思考、點頭、拒絕、同意、比讚、勝利、拍手、慶祝、擁抱、親親、比心、早安、晚安、歡迎、吃飯、喝茶、工作、讀書、運動、跳舞、音樂、遊戲，以及貓咪、狗狗、兔兔、小熊等。

每個顏文字都有分類標籤，新增項目另附情緒、動作或用途等標籤，方便下拉勾選與篩選。例如「擁抱」同時標記「安慰、親密」，「工作」標記「上班、日常」，「貓咪」標記「動物、可愛」。點左側標籤篩選，也可搜尋「開心／开心／happy」「抱抱／hug」「工作／work」「讀書／study」「貓咪／cat」等關鍵字。更新及重新啟動時會自動補入新項目，保留既有項目的修改、收藏、使用紀錄及回收站狀態。

- 雙擊或選取後按 Enter：將顏文字以 **Unicode 純文字** 貼回原輸入框；不會轉成圖片或自動按發送。
- 點「只複製」或在素材格按 Ctrl+C：複製文字；可以拖曳文字到接受文字拖放的輸入框。
- 在顏文字區塊點頂部「＋ 顏文字」：輸入內容、名稱與標籤，儲存後會進入「我的顏文字」；右鍵顏文字可編輯或移除，編輯既有內建顏文字仍保留在內建區塊。
- 顏文字有各區塊獨立的收藏篩選、標籤及最近使用；圖片／原始檔案模式不影響顏文字貼上。

顏文字資料保存在 `.memedrop/library.sqlite3`，不需要放進 `memes`。更新時會自動升級舊資料庫並保留既有素材記錄；內建顏文字僅首次加入，不會在重新啟動時覆蓋你改過的名稱、內容、標籤、收藏或還原已移除項目。不同軟體使用的字型可能讓部分特殊符號看起來略有差異。

## 貼上模式與相容性

| 模式 | 行為 |
| --- | --- |
| 自動 | 靜態圖放入圖片剪貼簿；GIF、影片放入原始檔案剪貼簿 |
| 原始檔案 | 複製檔案，保留 GIF 動畫、影片與原始品質 |
| 圖片 | 以圖片貼上；GIF 僅使用單幀，影片需改用其他模式 |

App 會送出一次 `Ctrl+V`，**不會按 Enter 或自動點發送**。目標軟體必須支援圖片或檔案貼上，純文字欄位無法接收媒體。桌面版與網頁版、不同版本的聊天軟體行為可能不同；若未出現附件，試切換模式或直接拖曳到附件區。尚未逐一實機驗證上述六款聊天軟體。

若 Windows 不允許切回目標視窗、目標已關閉或權限不同，App 會保留剪貼簿並提示手動 `Ctrl+V`。建議 App 與聊天軟體都以一般權限執行。最近使用記錄的是成功送出貼上按鍵，無法確認聊天軟體是否接受附件或發送成功。

圖片支援 PNG、JPG/JPEG、WebP、BMP、TIF/TIFF；GIF 作為動圖分類。影片支援 MP4、WebM、MOV、MKV、AVI、M4V，實際預覽取決於內含編碼與 Qt 的解碼支援。動畫 WebP 可在預覽播放，但分類為圖片，請選原始檔案模式保留動畫。

## 資料與隱私

素材存於 `memes/`，標籤、收藏、使用紀錄及設定存於 `.memedrop/library.sqlite3`，錯誤日誌存於 `.memedrop/app.log`。App 不上傳素材、不使用網路服務、不監聽輸入文字。選擇複製／貼上會取代目前剪貼簿內容。

透過 App 修改檔名、調整區塊或使用回收站會保留原素材記錄。若在檔案總管重新命名或移動素材，掃描時仍會視為新素材；外部移除的檔案不再顯示，但保留其資料庫標籤，放回同一路徑即可恢復。請備份 `memes` 與 `.memedrop` 兩個資料夾，後者也包含回收站檔案。

## Docker 開發環境（預設）

開發相依套件與跨平台測試以 Docker 管理，使用 Docker Desktop 的 **Linux containers** 模式。宿主機不需安裝 Python 即可執行這些驗證：

```powershell
docker compose run --build --rm test
docker compose run --rm smoke
```

也可直接執行 `docker-test.bat` 依序執行兩項檢查。`test` 執行素材庫、標籤、Qt 介面與 MIME 剪貼簿測試；兩項 Win32 專用測試在容器中會明確跳過，需另在 Windows 驗證。`smoke` 在離屏環境啟動完整介面，截圖及成功標記寫入 `.memedrop/docker-preview/.memedrop/`。測試使用獨立暫存素材，不會修改你的 `memes` 或正式素材資料庫。

進入可持續使用的開發容器（原始碼掛載在 `/workspace`）：

```powershell
docker compose --profile dev up --build -d dev
docker compose exec dev bash
# 容器內：
python -m unittest discover -s tests -v
python main.py --smoke-test --library /tmp/memedrop-preview
exit
docker compose --profile dev down
```

**Windows 桌面整合仍在宿主機執行。** Docker 容器用於開發／測試，不能直接取得宿主機的聊天輸入視窗或全域快捷鍵；容器的剪貼簿也不是 Windows 使用者的剪貼簿。日常使用雙擊 `start.bat`，使用已打包的 Windows App，不需本機 Python。容器內沒有將 Win32 呼叫冒充為成功的行為。[Windows 容器的桌面應用限制](https://learn.microsoft.com/en-us/virtualization/windowscontainers/quick-start/lift-shift-to-containers)

Docker 建置僅包含程式碼、測試及相依清單；`.venv`、`memes`、資料庫、Git 與私人設定不進入映像檔。`dev` 服務為方便編輯會掛載專案資料夾；`test` 與 `smoke` 使用映像檔內的程式碼，所以修改後請加 `--build`。

本機測試中上游下載緩慢，因此 Dockerfile 預設使用 [Debian 公開鏡像列表](https://www.debian.org/mirror/list)中的清華鏡像與[清華 PyPI 鏡像](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/)，保留 HTTPS 及 Debian 套件簽章驗證；不會修改宿主機套件來源。可執行 `docker compose build --build-arg DEBIAN_MIRROR=https://deb.debian.org --build-arg PYPI_INDEX=https://pypi.org/simple test` 改用上游來源。

## Windows 原生驗證與打包

全域快捷鍵、原生剪貼簿與 `.exe` 打包需要 Windows 環境；Linux 容器不產生 Windows 執行檔。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```
